# CHINIDEX

Aplicación web: https://chinoforeva.github.io/chinidex/

Esta distribución contiene únicamente el frontend público. Las cuentas, colecciones, catálogos y modelos permanecen en el servidor privado.

Al abrirla, configura la URL HTTPS del servidor CHINIDEX con API v3. El servidor debe permitir el origen `https://chinoforeva.github.io`. GitHub Pages aloja los archivos web; el servicio privado se despliega por separado.

## Android

La aplicación nativa Android se ha renovado con Material 3, búsqueda, inventario, álbumes y cámara. El APK de revisión se entrega por separado y utiliza un identificador distinto para conservar la instalación anterior. La actualización de producción requiere la clave de firma original y pruebas en dispositivo.

## Publicación

GitHub Pages utiliza la rama `main`, carpeta raíz. Esta distribución no incluye bases de datos, credenciales ni el backend.
